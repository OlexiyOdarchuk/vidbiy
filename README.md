# Відбій

Android-будильник, що спрацьовує після відбою повітряної тривоги. Коли тривога застала вночі чи вранці, можна спокійно спати й прокинутися одразу після відбою, наприклад, щоб встигнути на онлайн-пару.

## Як це працює

1. Натисніть **«Розбудити після відбою»**. Фоновий сервіс раз на 20 секунд перевіряє стан тривоги в обраному регіоні.
2. Коли тривога закінчується, на весь екран вмикається гучний будильник, навіть у беззвучному режимі й на заблокованому телефоні.
3. Після **«Вимкнути»** сервіс зупиняється. Поки будильник не ввімкнено, програма у фоні не працює.

Якщо ввімкнути будильник, коли тривоги немає, він чекатиме наступної тривоги й спрацює після її відбою.

## Можливості

- Вибір області або міста зі спецстатусом. Тривога в будь-якому районі чи громаді області вважається тривогою в області.
- **«Не будити після»**: після заданого часу будильник вимикається без сигналу.
- **«Будити, якщо зник зв'язок»**: сигнал, якщо жодне джерело даних не відповідає понад 5 хвилин.
- «Ще 5 хвилин», поступове наростання гучності, вібрація.

## Джерела даних

| Джерело | Ключ | Примітка |
|---|---|---|
| [siren.pp.ua](https://siren.pp.ua/) | не потрібен | обгортка над api.ukrainealarm.com, основне джерело за замовчуванням |
| [ubilling.net.ua](https://wiki.ubilling.net.ua/doku.php?id=aerialalertsapi) | не потрібен | запасне джерело |
| [alerts.in.ua](https://devs.alerts.in.ua/) | потрібен власний | необов'язкове, ключ вводиться в налаштуваннях |

Якщо основне джерело недоступне, програма по черзі звертається до інших.

> Жодне з цих API не гарантує 100% надійності. Для важливих подій варто мати запасний звичайний будильник.

## Встановлення

Завантажте APK з [Releases](../../releases) і встановіть, дозволивши «Встановлення з невідомих джерел». У програмі дайте дозволи на сповіщення, повноекранний показ і роботу без обмежень батареї.

## Збирання

Потрібні JDK 17+ і Android SDK (compileSdk 36).

```sh
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

Мінімальна версія — Android 8.0 (API 26). Стек: Kotlin, Jetpack Compose, Material 3.
